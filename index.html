DAILY PLAN

每日行程

09.25DAY 01
广州 → 洛阳中秋回家，只做一件事：团圆
交通高铁｜广州南 → 洛阳龙门
建议时间上午出发，17:00 前抵达
强度轻松
出发前吃好早餐，给进站和安检多留一点时间。
下午抵达洛阳后直接回家，不加任何景区。
晚上一家四口中秋家宴、聊天、月饼和合照。
预约提醒｜车票放出后优先选择白天直达；夫妻二人二等座即可。
09.26DAY 02
洛阳家庭日慢下来，陪爸妈过一天日常
交通市内步行 / 家庭用车
建议时间全天留白
强度很轻松
上午逛菜市场、喝汤、陪爸妈聊天。
下午午睡；有精神就去洛浦公园散步。
晚上一起检查北京行李和证件。
随身清单｜身份证、常用药、舒适鞋、薄外套、保温杯、充电宝。
09.27DAY 03
洛阳 → 北京不赶早，把体力留给北京
交通高铁｜洛阳龙门 → 北京西
建议时间下午出发，19:00 前抵达
强度适中
上午继续在家，中午和爸妈一起吃饭。
下午乘高铁前往北京，抵达后直接去酒店。
入住前门 / 和平门 / 宣武门附近，两间房。
入住提醒｜不坐最晚班次，21:30 前回到酒店休息。
09.28DAY 04
天坛 → 前门 → 大栅栏北京第一天，轻松进入节奏
交通地铁 + 步行｜约 8千—1.2万步
建议时间08:30 出门，19:30 回
强度适中
09:00—11:30天坛：祈年殿、回音壁、圜丘，慢慢走。
中午附近吃饭，留足午休和坐下来的时间。
16:00 后前门大街、大栅栏，吃家常北京味。
预约提醒｜提前购买天坛联票；故宫周一闭馆，今天不安排。
09.29DAY 05
八达岭长城 → 鸟巢 / 水立方全程最重要，也最费体力的一天
交通高铁 / 景区专线 + 打车
建议时间07:00—20:30
强度较高
上午八达岭长城，父母优先乘缆车，量力而行。
下午简单午餐后返城，酒店休息。
晚上鸟巢、水立方看夜景，不进场馆也足够。
预约提醒｜提前订长城门票及往返交通；给老人准备护膝、登山杖和水。
09.30DAY 06
天安门 → 故宫 → 洛阳父母的北京心愿，在国庆前完成
交通步行 + 地铁 + 晚间高铁
建议时间06:30 出发，18:00 后返程
强度较高
清晨天安门广场，给一家四口认真拍一张合照。
08:30—13:00故宫中轴线游览，减少支线，不求走遍。
下午至晚间午餐、取行李、前往北京西站，回洛阳。
重要预约｜天安门、故宫均需实名预约；证件随身，预留安检时间。
10.01—04DAY 07—10
洛阳休息 / 家庭日别人挤景区，我们在家过日子
交通不跨城
建议时间四天自由安排
强度很轻松
日常睡觉、吃饭、陪爸妈、见亲友。
可选家附近散步，避开龙门、白马寺等热门景区。
留白至少留一天完全不安排，让身体恢复。
行前提醒｜10月4日确认返程车次、证件和行李。
10.05DAY 11
洛阳 → 广州提前返程，避开最后两天高峰
交通高铁｜洛阳龙门 → 广州南
建议时间上午 / 中午出发
强度适中
上午早餐、告别，提前到洛阳龙门站。
途中高铁上休息，不再安排中转游玩。
抵达简单收拾，外卖或家常饭，早睡。
抢票提醒｜返程票是全程最高优先级之一，开售即订。
10.06—07DAY 12—13
广州休息给假期留一个柔软的结尾
交通不出远门
建议时间两天居家
强度很轻松

晚上早点睡，带着余裕结束长假。
最后提醒｜不再加景点。把休息本身，当作行程的一部分。
